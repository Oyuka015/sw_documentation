# AppFlowy Функциональ Бус Шаардлагууд (5 NFR) - SRS v1.0

### NFR-01: Програм эхлэх хурд (Cold Startup Performance) - Хурд ба Гүйцэтгэл
* **Тодорхойлолт:** Десктоп програм нь 8GB RAM бүхий хоёр цөмт стандарт x86_64 компьютер дээр 1.5 секундын (p95) дотор бүрэн ажиллахад бэлэн болно.
* **Хэмжигдэх хязгаар:** `< 1500 ms p95 эхлэх хугацаа` (Akamai вэб гүйцэтгэлийн стандартад үндэслэн Electron програмын 3000ms жишигтэй харьцуулсан).
* **Шалгах арга:** Шинжилгээ / Автоматжуулсан бенчмарк скрипт.

### NFR-02: Аюулгүй байдал ба Нууцлал (AES-256 Local Storage Encryption) - Аюулгүй байдал
* **Тодорхойлолт:** Систем нь локал SQLite өгөгдлийн сан болон тэмдэглэлүүдийг PBKDF2 ашиглаж үүсгэсэн AES-256-GCM шифрлэлтээр заавал шифрлэж хадгална.
* **Хэмжигдэх хязгаар:** `appflowy.db` файлыг шалгахад ямар нэгэн шифрлэгдээгүй энгийн текст олдохгүй.
* **Шалгах арга:** Аудит / Нарийвчилсан код шалгалт (Hex dump audit).

### NFR-03: Оффлайн горимын тасралтгүй ажиллагаа (Offline Mode Data Integrity) - Найдвартай ажиллагаа
* **Тодорхойлолт:** Програм нь сүлжээний холболт бүрэн тасарсан үед баримт засах болон өгөгдлийн сан удирдахад 100% офлайн ажиллах ба ямар ч систем гацах/гарах алдаа гаргахгүй.
* **Хэмжигдэх хязгаар:** 48 цагийн офлайн туршилтын турш програм 0 удаа гацна.
* **Шалгах арга:** Туршилт (Офлайн орчинд автоматжуулсан засах скрипт ажиллуулах).

### NFR-04: Модульчлагдсан архитектур (Modular Codebase Maintainability) - Арчилгаа
* **Тодорхойлолт:** Rust бэкэнд болон Flutter UI фронтэнд хэсэг нь бие биенээсээ хамааралгүй модульчлагдсан байх ба хатуу Foreign Function Interface (FFI) гүүрээр харилцана.
* **Хэмжигдэх хязгаар:** C-FFI / Dart гүүрнээс гадуур шууд өгөгдлийн сан руу хандсан UI код 0 байна.
* **Шалгах арга:** Кодын аудит (Статик код шинжилгээ болон хамаарлын график шалгах).

### NFR-05: Дэлгэц уншигчийн хүртээмж (Screen Reader Accessibility) - Хүртээмжтэй байдал
* **Тодорхойлолт:** Үндсэн засварлагчийн товчлуурууд болон цэсүүд WCAG 2.1 Level AA стандартад нийцсэн дэлгэц уншигчийн шошготой байна.
* **Хэмжигдэх хязгаар:** Үндсэн товчлууруудын 100% нь дууны шошгоны шалгалтыг давна (Chinchilla Ch. 7, p. 97).
* **Шалгах арга:** Шинжилгээ / Хүртээмжтэй байдлын автомат аудит.
