# Swagger UI vs Redoc: Decision Report 

Swagger UI болон Redoc нь нэг OpenAPI файлыг ашигладаг ч өөр өөр хэрэглэгчид зориулагдсан. Swagger UI-ийн "Try-It-Out" функц нь хөгжүүлэгчдэд browser-с баталгаажуулсан хүсэлт илгээх боломж олгодог тул туршилтын орчинд тохиромжтой боловч single-column layout-тай байдгаас нь том API дээр давчуу болж, хайлт нь зөвхөн tag-аар шүүхэд хязгаарлагддаг. Redoc-ийн three-panel layout нь navigation, тайлбар, кодын жишээг зэрэгцүүлэн харуулдаг. Мөн full-text хайлт нь уншихад хялбар болгодог. Гэвч Redoc нь бодит хүсэлт ажиллуулж чадахгүй. Иймд public reader view-д Redoc, дотоод туршилтын орчинд Swagger UI-г ашиглаж, хоёуланг нэг spec-ээс нийтлэхийг зөвлөж байна.
